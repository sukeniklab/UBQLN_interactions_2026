Code to identify how IDRs occupy STI1-1 or STI1-2 domains 

######

2. Fig5_E_D.py identifies peaks in probability (written in peak_ranges) and creates individual occupancy plots for each construct (individual_OccFold_Plots) that were used in 5E and 5D.
